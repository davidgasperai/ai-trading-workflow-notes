Title

Autonomy Requires Boundaries

Core Idea

An autonomous system becomes useful only when its authority is clearly limited.

Greater capability should never automatically grant greater access.

Why It Matters

AI agents can execute long chains of actions faster than humans can review them.

Without explicit boundaries, a minor error can propagate across tools, data, infrastructure, or financial accounts.

Impact on Nekonečný Mír

* Separate research from execution.
* Grant every agent only the minimum permissions it needs.
* Require human approval before live trading or modifying production systems.
* Record every tool call and material decision.
* Test agents inside isolated environments before expanding access.

Projects HQ Principle

Capability determines what an agent can do. Governance determines what it may do.
