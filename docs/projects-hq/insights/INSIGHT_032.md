Title

Safe Steps Can Create an Unsafe Path

Core Idea

Evaluating individual actions is not enough.

A sequence of individually permitted actions can combine into an outcome that the system was never intended to allow.

Security must therefore evaluate both actions and trajectories.

Why It Matters

Agentic systems operate through chains of tool calls, decisions, file operations, API requests, and delegated tasks.

Each step may appear legitimate in isolation.

The risk emerges from their composition.

A system that asks only “Is this action permitted?” may miss the more important question:

“What is this sequence of actions becoming?”

Impact on Nekonečný Mír

* Keep explicit permissions for every agent.
* Evaluate sequences of actions, not only isolated tool calls.
* Detect dangerous combinations of otherwise valid permissions.
* Revalidate system state before irreversible execution.
* Separate research, modification, risk approval, and live execution.
* Require human approval when a workflow crosses into financial irreversibility.

Projects HQ Principle

A safe action does not guarantee a safe trajectory.
