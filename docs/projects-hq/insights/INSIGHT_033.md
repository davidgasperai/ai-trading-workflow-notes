Title

Autonomy Should End Where Irreversibility Begins

Core Idea

AI systems can be given significant freedom when their actions remain observable, reversible, and contained.

As an action approaches an irreversible consequence, autonomy should decrease and verification should increase.

Why It Matters

Not every mistake has the same cost.

A research agent producing a poor hypothesis can be corrected.

A coding agent creating an incorrect experimental branch can be reverted.

A live trading agent deploying capital, exposing credentials, deleting critical data, or executing an irreversible external action may create consequences that cannot simply be undone.

The level of control should therefore depend not only on what an agent is capable of doing, but also on the reversibility of the outcome.

Impact on Nekonečný Mír

* Allow greater autonomy inside reversible research environments.
* Keep experiments isolated from production systems.
* Prefer simulation and paper trading before capital deployment.
* Increase validation as actions approach live execution.
* Require explicit approval for high-impact irreversible actions.
* Preserve rollback paths wherever technically possible.
* Design kill switches before autonomous execution is introduced.

Projects HQ Principle

The less reversible an action becomes, the less autonomy it should receive.
