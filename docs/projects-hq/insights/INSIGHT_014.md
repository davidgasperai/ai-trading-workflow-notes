Title

Separate Principles from Implementations

Core Idea

Technologies change.

Implementations evolve.

Principles endure.

Strong long-term projects distinguish between timeless ideas and the specific tools used to apply them. This separation allows systems to improve continuously without losing their identity.

Why It Matters

Many projects become difficult to maintain because their documentation mixes permanent principles with temporary implementation details.

When technologies change, teams often rewrite everything instead of updating only the implementation.

Keeping principles independent from tools creates stability while preserving the freedom to adopt better technologies in the future.

Impact on Nekonečný Mír

* Document enduring principles separately from technical implementations.
* Update workflows without rewriting the project’s philosophy.
* Design modular systems that allow components to be replaced independently.
* Keep Projects HQ focused on long-term knowledge rather than temporary configurations.
* Treat implementation as flexible and principles as stable.

Projects HQ Principle

Stable principles create flexible systems.
