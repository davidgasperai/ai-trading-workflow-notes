Date: 6 August 2026

Title

Authority Should Match the Task

Core Idea

An agent should receive only the authority required to complete its specific responsibility.

Intelligence, usefulness, and access are separate design decisions.

Why It Matters

Giving every agent the same permissions creates unnecessary risk.

A research assistant may need access to public information, while an execution component may need tightly constrained access to a broker or exchange. Combining both roles removes important safety barriers.

Impact on Nekonečný Mír

* Classify agents by autonomy and risk.
* Grant permissions individually, not globally.
* Separate research, code modification, validation, and execution.
* Revalidate permissions whenever an agent or model changes.
* Require human approval for irreversible financial actions.

Projects HQ Principle

The smallest sufficient authority creates the strongest system.
