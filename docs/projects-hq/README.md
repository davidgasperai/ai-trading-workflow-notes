# Projects HQ

Projects HQ is the long-term knowledge base of Project Nekonečný Mír.

It captures strategic insights, architecture decisions, research principles, workflow improvements, and long-term project knowledge.

## Purpose

The purpose of Projects HQ is to preserve important project thinking in a structured and reusable form.

Daily information is useful, but long-term value comes from identifying ideas, principles, and decisions that can guide the project over time.

## Structure

This section will gradually include:

- strategic insights
- weekly and monthly summaries
- architecture notes
- research principles
- agent design ideas
- important project decisions

## Status

This section is in an early stage and will evolve as the project develops.
