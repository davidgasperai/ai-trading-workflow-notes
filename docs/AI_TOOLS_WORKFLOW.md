# AI Tools Workflow

## Purpose

This document describes how different AI and research tools are used together within the project workflow.

The objective is to combine the strengths of multiple tools while maintaining transparency, reproducibility, and long-term knowledge retention.

## Workflow Overview

### ChatGPT

Used for:

- brainstorming ideas
- research discussions
- workflow design
- documentation support
- strategic thinking

### TradingView

Used for:

- market analysis
- hypothesis testing
- strategy development
- visual chart review
- performance evaluation

### Obsidian

Used for:

- private research notes
- idea collection
- long-term knowledge management
- project checkpoints
- local documentation

### GitHub

Used for:

- public documentation
- workflow transparency
- version control
- issue tracking
- project roadmap management

### VS Code

Used for:

- script development
- automation experiments
- repository management
- coding projects
- local editing

## Philosophy

No single tool solves every problem.

The workflow is designed around combining specialized tools while preserving context, research quality, and long-term learning.

## Future Expansion

Potential future additions include:

- Claude Code
- local AI agents
- automation pipelines
- database storage
- reproducible research environments

## Status

This document represents the current project workflow and will evolve over time.
