# Workflow Rules

## Core Principles

- Prefer documentation over memory.
- Record important decisions.
- Separate research from conclusions.
- Keep experiments reproducible.
- Avoid optimization without evidence.
- Use version control for meaningful changes.

## Research Rules

- Define the objective before starting.
- Record sources when relevant.
- Distinguish facts from assumptions.
- Document unexpected findings.
- Review conclusions before acting.

## Repository Rules

- Small commits are preferred.
- Commit messages should describe the change.
- Public repository remains educational.
- No financial advice or trading signals.

## Continuous Improvement

- Improve documentation regularly.
- Review workflows periodically.
- Maintain consistent repository activity.
